# Antarctic Ocean Risk-Aware Navigation — Frontend

React + Vite + React Three Fiber frontend for the Antarctic Ocean Intelligence
prototype.

## Demonstration data warning

The application currently consumes SYNTHETIC DEMONSTRATION DATA from the
FastAPI backend. It is not real scientific observation data and must not be
used for real navigation.

## Windows setup

```powershell
cd frontend
npm install
npm run dev
```

Open http://localhost:5173

The frontend expects FastAPI at http://localhost:8000.

## Build check

```powershell
npm run build
```
